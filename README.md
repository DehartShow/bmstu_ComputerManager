# Computer Management System

Это приложение для управления данными о компьютерах, которое позволяет добавлять, редактировать, удалять и сохранять информацию о компьютерах в XML файле. Оно предоставляет удобный графический интерфейс для взаимодействия с пользователем и включает основные функции работы с данными о компьютерной технике.

## Функции программы:
- **Добавление компьютера**: добавление нового компьютера с детальной информацией, такой как тип, инвентарный номер, производитель, модель, MAC-адрес, операционная система и дата.
- **Редактирование данных компьютера**: возможность редактировать данные уже добавленных компьютеров.
- **Удаление компьютера**: удаление компьютера из списка по инвентарному номеру.
- **Сохранение данных**: сохранение всех изменений в XML файл, чтобы информация сохранялась между запусками программы.
- **Загрузка данных**: загрузка данных о компьютерах из XML файла при старте программы.

## Структура XML файла:
Программа использует формат XML для хранения данных о компьютерах. Пример структуры XML:

```xml
<Computers>
  <Computer>
    <Type>Desktop</Type>
    <InventoryNumber>12345</InventoryNumber>
    <Manufacturer>Lenovo</Manufacturer>
    <Model>ThinkPad</Model>
    <MACAddress>00:14:22:01:23:45</MACAddress>
    <OS>Windows 10</OS>
    <Date>2023-12-10</Date>
  </Computer>
  <!-- Дополнительные компьютеры -->
</Computers>
